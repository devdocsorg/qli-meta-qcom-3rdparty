# Getting started with meta-qcom-3rdparty

This tutorial was generated by the Hosted Docs DocsGen pipeline from the public fork of Qualcomm Linux `meta-qcom-3rdparty`.

## What this layer is

`meta-qcom-3rdparty` is a Yocto/OpenEmbedded layer that packages third-party board support for Qualcomm Linux. The fork used here is `devdocsorg/qli-meta-qcom-3rdparty` (branch `wrynose`).

## Typical workflow

1. Add the layer to your `bblayers.conf`.
2. Choose a machine from the layer's `conf/machine` files.
3. BitBake an image that includes the board's firmware and kernel fragments.
